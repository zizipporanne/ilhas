# 🏝️ Ilhas

Um projeto interativo web __da região de Florianópolis, construído com Vite e Three.js para renderização de mapas, shaders e visualização 3D.

---

## 🚀 Tecnologias Utilizadas

- **[Node.js](https://nodejs.org/)** — Ambiente de execução JavaScript
- **[Vite](https://vitejs.dev/)** — Build tool rápido e servidor de desenvolvimento
- **[Three.js](https://threejs.org/)** — Biblioteca 3D para WebGL
- **[Git LFS](https://git-lfs.github.com/)** — Gerenciamento de arquivos grandes e ativos 3D

---

## 📋 Pré-requisitos

Certifique-se de ter instalado na sua máquina:

- **Node.js** (versão 18+ recomendada)
- **npm**, **pnpm** ou **yarn**
- **Git** e **Git LFS** (para suporte aos arquivos pesados da pasta `_sources/`)
